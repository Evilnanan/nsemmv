# 执行者绝招增伤：倍率与重复装备

Daybreak 2.1.9 Beta2-Hotfix1 的 7034900、7034901 都发放根效果 7501200。原生攻击消费者对符合分类的攻击给出 1.2 倍攻击倍率；重复装备同一版本或混用两个版本，仍只有一份根效果，倍率仍为 1.2。

本批仅将两个词条的叠加说明改为“不可叠加”。具体兽形态动作范围仍未解明，未改成“绝招期间所有伤害”。[探针](../../tools/probe_executor_ultimate_attack.py)与[证据](../../data/effect-executor-ultimate-attack-evidence.json)固定 EXE、regulation、SpEffect、AttachEffect、AtkParam_Pc 哈希。`gameplayVerified` 为 false。

## 原生执行

`4FEA30 → E6E150 → E6E3B0` 从真实 AttachEffect 行选出根效果。两个版本各自使用 1／2／3／6 份词条，检查角色代码 0～10：执行者 8 和中性对照 0 接受，其他职业拒绝。两版本各 0～3 份的 16 种混合输入也经过选择器。

`50D060 → 5057D0 → 50ACD0` 执行插入与资格处理。7501200 为类别 20、状态 0、永久效果；重复插入仅保留一个同 ID 节点。这里没有把抽取互斥或 AttachEffect 的 compatibilityId 当作叠加依据。

`E6D530 → E6D3E0` 将真实攻击行的五个分类字节转换为位集，再调用 `502830 → 511010`。分类 123 命中时，物理／魔力／火／雷／圣五条攻击倍率通道均返回原始单精度值 1.2000000476837158；不命中时均为 1。所有 59 个命中行，加上 216 种分类组合的代表，共 273 个不重复攻击行，在 0／1／2／3／6 份根效果下检查。

来源类型 3／4／5／10 不应用该增益；这些是显式原生上下文输入，未将其强行命名为玩家可识别的攻击动作。分别设置停用位 1、2、0x40000、0x80000000 后，增益消失。删除唯一根节点后增益消失，重新插入后恢复。经过 1／40／300 秒更新仍保留同一根节点，不因此增加界面持续时间。

1580 项检查：选择 88、攻击分类 1365、两版本混用 16、来源类型 78、停用 16、移除／重插 8、时间更新 9。分配、库存枚举、角色身份与真实 PARAM 查找为夹具；选择、去重、分类转换与数值消费者使用原始机器码。
