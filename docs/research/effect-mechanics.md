# 词条生效机制研究

本轮覆盖当前 MMV 中 885 个可获取遗物定义涉及的 **637 个不同词条**，包括商店遗物。完整逐条记录见 [`data/effect-research.json`](../../data/effect-research.json)：每个词条都有根效果、状态类型、已展示数值的来源、叠加证据和待解问题。目录中的其它能力保留基础详情，但不计入这 637 个遗物词条。

| 当前进度 | 数量 |
| --- | ---: |
| 已建研究记录 | 637 |
| 有可展示的字段或替换法术 | 447 |
| 其中有已解读的数值字段 | 432 |
| 其中仅有替换法术名称 | 15 |
| 已核对原生叠加处理 | 208 |
| 用户反馈确认普通版与 +1 版可叠加 | 2 |
| 尚未解析到可展示字段 | 190 |

这些是不同维度的覆盖数，不能相加作为“完全解明”数量。`decoded-fields` 只表示解读了数值字段；`native-analysis` 表示当前代码处理已核对，不表示完成了整局、多人或所有边界的游戏实测。没有完成游戏实测的条目统一保留 `gameplayVerified: false`。研究记录不进入主界面。

## 固定输入与复现

- MMV：Daybreak 2.1.9 Beta2-Release，regulation `10350000`。
- regulation SHA-256：`3305ac374b4da1db440e2b6644bc2c3c0ae96b98df9627f1a0e7a2b06d265c06`。
- PC EXE：1.3.3.0，SHA-256 `9545e8732919bb6a63904cb73223641b3c4f9a67869be5722612acca413e8b3a`，以下均为 RVA。

仓库只保存必要派生数据及验证输出，不保存游戏程序、完整 PARAM 或个人存档。提取时使用 Smithbox 的当前版本定义，过滤不适用于 `10350000` 的字段。输出后重新读取 JSON；`--research` 另外导出实际 PARAM 字节和 common EMEVD 指令，供本地只读分析。

```sh
dotnet build tools/ExtractEffectDetails/ExtractEffectDetails.csproj -p:SmithboxDir=<Smithbox目录>
dotnet tools/ExtractEffectDetails/bin/Debug/net10.0/ExtractEffectDetails.dll <Smithbox目录> <游戏目录> <MMV的mod目录> <临时目录>/extracted.json --research
# Python 环境需要 pefile、unicorn。
python tools/probe_effect_mechanics.py <游戏目录>/nightreign.exe <临时目录>/extracted.SpEffectParam.param <临时目录>/extracted.json data/effect-native-evidence.json --hero-params <临时目录>/extracted.HeroStatusParam.param
python tools/build_effect_details.py --extract <临时目录>/extracted.json
```

仅复现浏览器数据和研究记录不需要游戏文件：`python tools/build_effect_details.py`。生成器同时核对 regulation、EXE 身份及原生验证记录；研究记录绑定验证文件 SHA-256。CI 检查生成结果与提交一致。

## 原生执行检查

[`probe_effect_mechanics.py`](../../tools/probe_effect_mechanics.py) 在 Unicorn 内执行原 EXE 的指令，使用实际 MMV 的 1024 字节 SpEffect 行、28 字节 HeroStatus 行，构造效果链表和有效/无效节点。字段偏移先与提取器解码结果逐行核对。遇到未准备的依赖或超过执行预算即失败。

共 **493 组检查**：7 组匹配谓词、10 组能力值、36 组攻击倍率、3 组承伤倍率、8 组冷却、5 组发现倾向、24 组绝招累积、400 组角色等级调整。结果保存为 [`effect-native-evidence.json`](../../data/effect-native-evidence.json)。

仅三个外部依赖被替代：`E6D630` 无武器 PARAM 的查询，`E78730` 用实际 HeroStatus 字节实现的表查询，`E78720` 表包装对象清理。倍率、实例匹配、等级区间选择、插值及取整均执行原生代码。没有启动游戏进程，没有模拟完整远征。

## 已确认的处理

### equip-injection / instance-matching

`E6E3B0` 读取 Attach 的三个被动效果。`4FF520` 收集各项被动效果，`4FF2E0` 逐项派发；`4FEA30` 另处理装备时的 exclusivity 与角色允许条件。因此只对根节点简单、没有额外触发链或状态条件、没有装备 exclusivity 限制的类别 10 / 状态 0 词条发布通用叠加结论。

效果添加路径 `50D060` 调用 `510B20`、`510B70`、`510BD0` 和 `511450`。已检查的类别 10 不因相同 ID 复用现有节点；类别 20 会复用相同 ID。不能将这个结论扩大到所有类别，亦不能只从词条名字或菜单筛选标志推导叠加方式。

### attributes / attack / defense / cooldown

- `502300`：八项能力值增减相加，包括重复与不同等级。
- `502830`：已生效且通过攻击过滤的五通道 AttackRate 相乘。来源类型 3、4 是魔法、祷告通道；三份“强化魔法和祷告＋２”得到 `1.14³ = 1.481544`。属性攻击与法术强化可同时进入相乘路径。
- `503800`：承伤倍率相乘。三份魔力承伤 `0.84` 得到 `0.592704`。
- `508480`：有效节点的技艺冷却时间倍率相乘，带最终限幅；不是将“缩短百分比”直接相加。
- `511010` 的攻击分类过滤和相关 PARAM 同时约束增攻。分类 103 是防御反击，130 是近战；不能把所有类别字段都显示成“指定法术类别”。魔法与祷告适用标志也不替代分类判定。

### weapon-count / discovery

三武器条件词条为状态 2100、类别 20；`wepTypeTriggerCount` 为 3。同一种效果重复使用会复用节点，不再获得第二份数值。不同种类的效果在各自条件成立时分别生效。原生攻击计算中同时放入三弓与三短剑的有效节点，倍率为 `1.2 × 1.2 = 1.44`；这项隔离检查不模拟换武器动作。

`5072D0` 返回有效链表中遇到的第一个状态 2122 的 `weaponTypeDiscovery`。弓/手杖顺序互换时返回类型随之变化。详情因此写“采用生效列表中的第一个”，不声称界面左边的遗物必定优先，也不把多个倾向解释为各自独立增加概率。

### gauge

- `508BE0` 汇总 `ultimateArtGaugeRate`；`48BEF5` 的调用点位于按时间推进的自然增长循环。
- `508B90` 汇总 `ultimateArtGaugeChargeRate`，额外要求节点标志 4；`6CC0DC` 的攻击结算调用点使用该结果。
- `508C70` 的周期效果增长也读取 ChargeRate，对正向增长应用倍率。

“自然累积绝招量表＋１”实际两个字段都是 1.05；“降低绝招量表累积”均为 0.85。两个通道分别相乘，不能把它们相乘后称为一次增长的总倍率，也不能把 ChargeRate 标成自然增长。

### hero

状态 2123 由 `501D30` 遍历并调用 `6C8A60`，根据 `heroStatusModifier` 读取连续的 HeroStatus 行。按 `totalLevel` 选择左右端点，中间等级交给 `6C2390` 线性插值，以单精度运算，最后 `cvttss2si` 向零取整；超出最后端点沿用最后一行。

全部 20 类调整均执行 1～20 级，共 400 次。例：“【隐士】提升智力、信仰，但降低集中力”：1 级为集中力 -2、智力 +2、信仰 +2；2 级为 -3、+2、+2；12 级起为 -13、+12、+12。详情合并数值相同的连续等级，保留未知的跨遗物重复规则。

## 已解读字段及尚未完成的链

- 抵抗力以点数展示：例如抗毒普通版 +75、+1 版 +110，负面抵抗力为 -80。当前尚未发布它们的跨遗物叠加结论。
- `changeHp/Mp/StaminaRate` 的单位已是百分数，不再乘 100；负值恢复，正值消耗。固定恢复与按最大值恢复分开。连续攻击回 FP 的子效果是最大 FP 的 5%，累积阈值 32 不能直接解释成“32 次攻击”。
- 47 类出击道具存在两条状态 2102 分支，第二条要求状态 2226。火焰壶每条分支为 2 个，不能无条件展示成 4 个。状态 2226 对应效果 7999080 / 8882300，但其实际获取及发放时序尚未解明。
- 混合魔法词条的显式链可见 +35% 攻击倍率与 +30% 法术 FP 消耗，子节点各 3 秒。其它强化效果、真实刷新时机、与动作/Bullet 的关系仍待追踪。
- 普通杀敌回绝招与 +1 版的可叠加来自用户反馈；两条 Kill/GetSoul 通知不直接相加为每次击杀的收益，同版重复仍待查。
- 特殊地点攻击成长已经定位到实际 common 事件 1400/1402/1407/1408/1409 和标记 7060001；事件分别授予 7060000 或 7060002，再替换为类别 204 的成长效果。当前 MMV 的 1400 是三档本地计数，不能套用其它版本的七档结论。成长档位推进、地点计数来源及重载恢复尚未闭环，暂不将推测总倍率写入详情。
- 学者样本、受击异常、低血量恢复等仍需补 native 状态分派、Behavior/Bullet 或动作引用。显式引用遍历到数值节点不代表已经解释了全部触发条件。

后续按逐条记录中的 `openQuestions` 推进，优先消除相同底层实现的一组问题，再核对各个词条的差异和边界。所有结论都绑定当前输入，更新 MMV 或游戏程序必须重新验证。
