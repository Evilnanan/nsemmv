# 切换武器后的随机附魔

`7035700` 在切换武器后，为切换的那只手添加一种属性攻击力：魔力 26%、火 25%、雷 25%、圣 24%，基础附魔值均为 **20**，持续 **10 秒**。重复装备不增强附魔。同一只手再次获得随机附魔时替换旧随机附魔并刷新时长，左右手分别保留。已确认同一只手与火油脂互相覆盖，后施加者生效；不把这一结论泛化到所有优先级的武器附魔。

只对可附魔武器生效。双手共持左手武器时，右手不会新获得随机附魔。已存在的附魔在换成不可附魔武器后失去攻击加成，但节点仍按原剩余时间倒计时；直接改变持握方式或移除遗物根节点也没有立即删除该节点。这些是隔离字段变更及根移除的结果，完整切换动作还可能产生新的附魔，不能据此推断所有装备重建流程。

## 触发与持握方式

当前 HKS 的 `ExecWeaponChange` 设置切换的手，`WeaponChangeCommonFunction` 检查根 `7035700`、动画标记 `7035701` 以及四个短暂的防重复节点。随机数范围 1～100，分支边界 75／50／25，因此概率不是四个 25%。原有 `effect-script-evidence.json` 已执行 212 个分支输入。

本批接通三个实际 TAE（2000／2002／2003）各八个切换动画的 Type66 标记。`27D0F10 → 27D0400 → 410CA0 → 3C8BE0` 使用真实原始数据、原生重定位、迭代和分派；分别验证 0／1／3 份根效果。活动标志为显式输入，完整动画调度、Type66 持续维持与 HKS 冷却窗口仍列为未解边界。

HKS `SetStyleSpecialEffect` 在双手共持左手武器时添加 `100621`（状态 322），其他持握方式添加 `100620`（状态 323）。两标记类别 158，原生容器替换旧标记。右手四个附魔种子要求状态 323，左手种子没有该条件。16 种持握转换在 Lua 中运行实际函数，并将输出通过原生授予函数送入容器。

## 附魔节点与攻击消费

八条种子链 `7035702/4/6/8/10/12/14/16 → seed+1` 覆盖四种属性及两只手。右手有效附魔类别 162、左手 163，优先级均为 0；魔力／火／雷／圣的状态分别是 64／62／151／205。种子发放时，`3CF020` 经角色虚函数 +250 取得对应手的武器，检查实际武器行 +0x106 的 `isEnhance` 位。

攻击侧执行 `E6D530 → 502830 → 511010 → EA1B00 / EA1D40`，验证当前武器可附魔标志、手、攻击分类和真实攻击标签。832 组检查覆盖八条附魔、四种持握方式、13 个内部攻击类型及可／不可附魔武器。内部类型 11、12 的消费行为已记录，但未映射为玩家动作名称，不将它们随意解释为双持攻击或法术。

另以当前全部攻击行的「标签集合、附魔点数修正」分组，覆盖 395 组／3160 次消费。结果为 `20 × spEffectAtkPowerCorrectRate_byPoint / 100`；修正为零的攻击不会得到加成。该修正属于动作数据，不是随机词条的额外概率或叠加规则。页面保留基础附魔值，不罗列每个动作的内部修正。

## 覆盖、计时和延长

64 种前后随机附魔组合验证同手替换、异手独立；同属性再次获得也刷新持续时间。30／60／120 Hz 下均验证十秒寿命，边界允许原生更新的一帧误差。首次种子进入列表与有效附魔激活隔着维护步骤，不将内部零秒种子当作玩家增益寿命。

32 种与左右手火油脂 `3160/3162` 的顺序组合验证同手后者生效、异手分别保留。法术持续时间延长 `7006400/8330500` 和油脂延时根 `7030940` 均不延长这八条随机附魔。油脂延长的额外桥接链不是这些随机附魔的过期替换链。
