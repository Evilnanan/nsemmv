# 隐士混合魔法强化

基础批确认 `7034200`、`7034201` 两个同名目录版本的共同增伤、耗蓝及重复装备规则。后续已补齐[纯圣防护](mixed-magic-defense.md)，其余附加效果继续研究。

- 混合魔法攻击倍率 +35%。
- 魔法、祷告的 FP 消耗倍率 +30%；三个法术耗蓝通道均为 1.3。
- 重复装备，包括两个同名版本混用，不叠加增伤或耗蓝增幅。
- 与所测降低法术消耗效果按乘法组合，例如 1.3 × 0.84 = 1.092。

页面不再显示“三秒”持续时间。三秒属于装备根持续刷新的内部叶节点寿命，不是只强化三秒的主动增益。完整卸装流程另行研究；直接删除根后旧叶节点自然到期，不等于游戏实际卸装行为。

## 原生路径

两个 AttachEffect 均指向 `9200006`，只允许隐士。通过 `4FEA30 → E6E150 → E6E3B0` 执行真实选择，角色 7 及通用对照 0 接受，其他角色拒绝；两版本混合的四份输入解析出四次相同根发放。根和叶节点类别均为 20，原生插入仅保留一份。

根永久存在，每 0.2 秒发放桥 `9200007`。桥寿命 0.11 秒、周期 0.1 秒，周期发放增伤叶 `7034201`，到期替换为耗蓝／状态叶 `7034200`。后两者寿命三秒。30／60／120 Hz、0／1／3／6 份输入均验证实际授予和维护，旧叶寿命被反复刷新。

攻击执行真实 AtkParam 标签转换 `E6D530` 和倍率消费 `502830`。216 组实际标签组合在四种装备数量下验证：法术上下文中，包含标签 16 才得到 1.35，其余为 1。另测 13 个内部攻击类型：3／4／10 接受，其他不接受。当前 14 个混合魔法 Magic 行均包含子分类 16，原始 +0x28 与导出 `spEffectCategory` 均为 3；没有把单纯出现这个标签的所有攻击都称为混合魔法。

耗蓝执行 `507310`、`507410`、`5081E0`、`5061B0`。前三个法术通道返回 1.3，第四对照保持 1。六种减耗节点分别与 0／1／3 份根组合，前三通道按乘法计算；探针读取倍率，尚未模拟完整实际 FP 扣除、整数取整和资源不足分支。

叶节点的四种禁用掩码逐一排除相应收益；增益时间延长 `7006400`／`8330500` 不改变两个三秒内部叶的寿命。直接删除根后持续更新四秒，增伤和耗蓝均回到 1。

## 复现与边界

```sh
python tools/probe_mixed_magic.py <EXE> <extracted.json> data/effect-mixed-magic-evidence.json
```

输入为当前固定版本 EXE 和由同一 regulation 导出的 SpEffect、AttachEffect、AtkParam、Magic 原始参数。正式探针共 **999** 组记录：装备选择 33、维护 12、攻击标签 864、类型 52、减耗组合 18、禁用 8、延长对照 6、根移除 6。

身份、物品句柄、内存分配和参数查找为明确夹具；实际选择、插入、授予、维护、标签转换、倍率消费及计时执行原指令。`gameplayVerified=false`。完整施法、弹体构造、场景碰撞、各附加分支、实际资源扣除、DLL 改写、装备重建、死亡、重载和联机仍保留研究问题。
