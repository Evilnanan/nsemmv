# 送葬者蓄力法术命中后的保护

Daybreak 2.1.9 Beta2-Hotfix1 的 7037500、7037501 同时使用根效果 7037100。命中符合分类的蓄力攻击后，7037101 提供 **35% 减伤、强韧度损耗降至 0，持续 10 秒**。同版重复装备、两个同名版本混用均不增强效果；再次有效命中刷新持续时间。

虽然游戏词条名称写“祷告”，蓄力魔法也可以触发。本批以辉石彗星、投火和辉石指爪的蓄力／未蓄力版本核对，前两种分别提供魔法和祷告对照，辉石指爪补充新版法术。界面改用“蓄力魔法／祷告命中后”。“延长魔法、祷告的有效时间”不延长此保护。

[探针](../../tools/probe_undertaker_charged.py)与[证据](../../data/effect-undertaker-charged-evidence.json)固定 EXE、regulation、SpEffect、AttachEffect、AtkParam_Pc、Magic、Bullet、TAE、行为图和 HKS 输入；`gameplayVerified` 为 false。

## 装备与命中消费者

`4FEA30 → E6E150 → E6E3B0` 使用真实 AttachEffect 行，检查两个版本各 1／2／3／6 份、角色代码 0～10。只有送葬者 10 和中性对照 0 接受。两个版本各 0～3 份的混合输入也经过选择器，不从抽取互斥字段推导叠加规则。

根为状态 2103、类别 20，`atkOccurrenceSpEffectId=7037101`，过滤分类 110。原生 `50D060` 对重复根去重；`E6D530` 将真实攻击行的分类转换为位集，再执行 `505E90 → 50F230`。所有 164 个分类 110 攻击行及 216 种分类组合代表，合计 367 个不同攻击行，都在零／一／三份装备下检查。只有有根、分类匹配且节点未停用时才返回一个叶效果。

根的三种法术来源开关均开启。在显式来源类型 0～12、附加标志 0／32、攻击类别 0／6 的组合中，分类匹配的命中都可请求叶效果。并未把这些数字全部命名为可达游戏动作；全部攻击行的动作绑定仍待继续追查。

返回的命中结果由夹具插入攻击者容器。它验证原生命中筛选及结果后的数值处理，没有执行实际碰撞、完整目标投递或联机队列。

这些攻击行都有非零直接攻击数值，不以零伤害占位行作为唯一触发证据。Magic 原始字节 +28 的来源类型为 3／4，与魔法／祷告类别一致。

指针校验后的行为图包含 `MagicFireRight`／`MagicFireLeft` 的 45010／45110 动画，以及对应 `Cancel` 的 45011／45111 动画。HKS 的 `IsChargeMagic` 检查 45011；左右 `MagicLoop` 在松开施法键等情况下进入 `Cancel`。这部分是静态关系检查，没有运行完整 HKS 或行为虚拟机。

每个法术的两只手、蓄力／未蓄力版本均读取实际原始 TAE，经 `27D0F10` 重定位和 `27D0400` 迭代，使用原始 Type 64 参数执行 `40EB30 → 3953C0 → 384800 → E91FD0`。蓄力版本的槽 1 选择上表右列弹体；未蓄力槽 0 选择左列。关闭事件活动输入则不请求发射。

`383D20` 作为终端请求记录器，记录原生选出的类型 1 和弹体 ID，随后以真实 Bullet 的攻击行接入命中消费者。实际弹体创建和碰撞未执行；选定法术、动画、事件活动窗口、角色身份与来源类型是显式输入。辉石指爪有多个发射事件，本批检查其第一个 Type 64，不宣称已逐个模拟所有子弹体。

早期施法夹具的选中法术组件与角色组件表 +100 重叠，误进入不存在的附加弹体组件查找。最终将选中法术组件移到独立区域，保留真实引用选择代码，完整检查重新运行。此错误属于夹具，未作为游戏限制或额外机制发布。

## 数值、计时与刷新

叶效果为类别 20，原生容器只保留一份。`503800` 的五个承伤通道均返回单精度 0.6499999761581421；`502270` 的强韧度损耗倍率为 0。这里证明的是强韧度损耗，不推导抓取或所有强制受击反应免疫。

在 30／60／120 Hz 下运行完整到期流程，10 秒后最多三个更新步内移除。分别装备零／一／三份延长词条，时长一致。第 4 秒和第 8 秒再次有效命中时，叶效果回到 10 秒，仍只有一个节点；第 18 秒附近到期。参数中的 `motionInterval=11` 没有增加可展示的周期恢复或触发冷却，界面不显示该间隔。

停用节点后两类减伤均消失。只从容器移除根，已经发放的叶仍按原时间结束，后续命中不再刷新；这不等于完整装备重建的行为已经验证。
