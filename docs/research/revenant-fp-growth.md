# 复仇者：发动能力时提升专注值上限（部分解明）

对象：AttachEffect `6500500`，Daybreak 2.1.9 Beta2-Hotfix1。

本记录只确认原生激活通知之后的增长、上限及通知去重。**尚未确认完整的游戏内触发来源和初始层数，不据此更新词典，也不计入已解明词条数量。** `gameplayVerified` 为 `false`。

## 已执行验证

`tools/probe_revenant_fp_growth.py` 使用锁定哈希的 EXE、SpEffectParam 和 AttachEffectParam，在隔离环境中执行原生指令。结果保存在 `data/effect-revenant-fp-growth-partial-evidence.json`。

- `4CC320` 启用分支从本机角色的效果容器调用 `507910`，读取 state `2119` 对应行的原始 `+0x3CC` 字段，得到 `7500501`；随后执行原生 `3C7FD0` 发放和 `3DB410` 成长处理。
- `7500500` 根效果重复插入会去重。分别使用 0、1、3、6 份根效果，连续发出 36 次组件激活通知：无根效果不增长；有根效果时，每次通知推进一级，第 30 级封顶，多份根效果不加速增长。
- 成长容器始终只保留 `7500501…7500530` 中的一行。`6C91F0` 的实际 FP 上限结果与当前行 `maxMpRate` 一致，并非将 30 行倍率相乘。

| 成长级别 | FP 上限倍率（原始单精度值） |
| --- | --- |
| 1 | 1.0159578323364258 |
| 20 | 1.319154977798462 |
| 21 | 1.3372403383255005 |
| 30 | 1.500009536743164 |

这里的级别来自组件通知测试，**不能直接解释为游戏中的召唤次数**。`AttachEffectParam.permanentSpEffectId=7500501` 的装备／恢复语义尚未核实，不能默认角色从零级开始，也不能默认装备即获得一级。

## 同一对象的重复通知

实际执行 `3C7F10 → 4B3370 → 4CC320 → 507910 → 3C7FD0`。类型 `0x26` 的组件查询使用已存在组件的测试替身，未执行组件分配和注册。

`3C7F10` 检查接收对象的 `+0x1F9` 字节最高位；首次处理后设为 `0x80`，后续调用直接返回：

1. 对象 A 的首次启用通知增长一级。
2. 对象 A 再次启用不增长。
3. 对象 B 的首次启用再增长一级。
4. 对象 C 首次收到停用通知不增长，但仍设置该位；随后启用也不增长。

此标志的生命周期／重置入口尚未确认。测试没有清除该位来制造额外触发。组件发放的受益者来自 GameMan 的本机角色指针，不是通知接收对象；这不等于已验证联机归属。

## 根效果、保留与边界

- 将根节点的禁用标志设为 `0x800C0003` 后，`507910` 仍会返回成长效果，仍能增长。不能假设该 getter 会像通常的数值 getter 一样过滤禁用节点；真实装备资格尚需上游验证。
- 从原生容器删除根节点后，不再产生新成长；已经获得的成长行仍保留。这里是容器移除，不是完整的装备重建。
- 对已有成长分别推进 1、15、40、300 秒，未到期。参数中成长行的持续时间为 `-1`，saveCategory 为 `9`；未将它解释为跨远征或跨读档永久保留。
- 共 177 项检查：成长 144、对象去重 20、根存在／禁用／移除 3、保留 10。没有执行游戏客户端、实际召唤、当前 FP 写入或联机。

## 后续追踪位置

静态发现 `3930F0` 有距离、候选对象、NPC 参数 `+0x26A`、概率和对象登记等分支。`519EF0` 成功后，`393614` 调用 `3C7F10(target, true)`。这条路径疑似敌人复生，尚未完整执行和绑定到游戏事件。

另一个启用调用位于 `390F30…391008`。扫描全部可执行 PE 节的 E8/E9 和 RIP 相对 LEA 引用尚未找到该入口的调用者；这不证明入口不可达。函数范围必须按 PE 异常目录的大小读取，不能把整个 `.pdata` 节当作函数表。

角色 TAE 2905 的 `551010/551020/551030` 含类型 1005、负载 0/1/2，以及类型 1006；这些事件尚未与上述激活函数建立原生调用链。现有 `40CD80` 是行为请求处理函数，不应因为地址接近其他 TAE 处理函数就假定它处理类型 1005。

仍需核实：正常家人召唤／敌人复生的实际入口、失败与重复处理、初始成长、对象标志重置、装备重建、死亡／远征／读档、最终整数和当前 FP 处理、MMV DLL 是否改变调用路径。
