# 学者：获得样本时获得卢恩

7036500 每新增一个样本获得 **1300 卢恩**。重复装备不提高奖励；一次新增多个样本分别计奖，已有样本记录不会再次计奖。增加或减少卢恩的倍率不影响这笔固定奖励。

[探针](../../tools/probe_scholar_sample.py)和[证据](../../data/effect-scholar-sample-evidence.json)固定 Daybreak 2.1.9 Beta2-Hotfix1 的 EXE、regulation、SpEffect 与 AttachEffect。`gameplayVerified=false`，不是完整游戏实测。

## 原生处理链

装备选择 `4FEA30 → E6E150 → E6E3B0` 接受学者和中性职业输入，其他职业排除。根 7036500 为类别 20、状态 2125，重复根去重。`analyzeAcquire_effectId` 位于原始行 +3EC，引用 7036501；后者类别 10、卢恩 1300，允许一次新增多个样本时保留多份奖励。

技艺处理函数 `3ED220` 中，`3EDDF6..3EDF18` 使用实际 `52C990/52CB00 → 3D1B30` 关系判断及目标标记筛选。显式目标类型 1、无排除标记时通过；类型 0／6／77 或目标 +1F8 的高位标记被排除。本批没有将所有内部类型编号命名为玩家可见对象。

`3CED70` 读取目标 +1B0，调用者使用低 16 位作为样本记录键。`3EDEAD..3EDF18` 查找已有记录，缺失时调用原生 `3EB550 → 3F1D10/3F10B0` 插入并平衡记录树，再增加本批新增样本数。这里只替换分配器末端，查找、插入、计数均执行原生代码。重复键不增加计数；高 16 位不同、低 16 位相同的控制输入仍被视为同一键。标识来源尚未追完，因此不把键直接称为“敌人种类”或“单个敌人的编号”。

`3EE0CA..3EE10B` 调用 `505C80` 获取第一个有效状态 2125 的奖励引用，再按新增样本数调用 `3C7FD0 → 3C80A0 → 3DB410` 实际发放。`505C80` 是没有异常展开条目的叶函数；只依据 `.pdata` 查找会漏掉它，不能据此判断不存在状态消费者。

奖励经 `5057D0 → 50ACD0` 更新后，实际 `6713D6..6713F8 → 505AF0 → 668300` 固定奖励路径关闭卢恩倍率，最终 `2098C0` 资源写入请求由记录器接收。本批没有实际写入存档或模拟最后的资源上限截断。

## 验证与边界

117 项检查：装备选择 44、样本去重 18、目标资格 24、固定奖励 27、根停用 4。零／一／三份装备、重复及混合样本、增加／减少卢恩词条均有对照。两条新记录得到 2600，三条得到 3900；重复分析已有记录为 0。同一奖励只在一次更新中出现。
