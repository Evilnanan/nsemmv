# 延长魔法、祷告有效时间

适用 Daybreak 2.1.9 Beta2-Hotfix1。[原生探针](../../tools/probe_spell_duration.py)和[证据](../../data/effect-spell-duration-evidence.json)固定 EXE、regulation、AttachEffect、SpEffect、Magic、Bullet 哈希。`gameplayVerified` 为 false。

| 词条 ID | 单份延长比例 | 同版重复 |
| --- | --- | --- |
| 330600 | +30% | 不重复 |
| 7006400 | +50% | 不重复 |
| 8330500 | +100% | 可叠加 |
| 8851300 | +45% | 可叠加 |
| 8851350 | +60% | 可叠加 |

当前可获取词条是 7006400，其余同名目录行单独保留结论，不因名称相同而当作相同效果，也不据此声称这些目录行可以正常抽取。

各份实际生效的延长比例相加。例如 +50% 与 +45% 与 +60% 合计 +155%，持续时间为原来的 2.55 倍；三份 +45% 是 2.35 倍，不是 1.45³ 倍。

## 实际选择和倒计时

`4FEA30 → E6E150 → E6E3B0` 执行装备选择。五种词条的排斥 ID 都是 -1，重复装备均被选择；330600／7006400 的类别 0 根在 `50D060` 插入时去重，其余类别 10 根保留重复实例。

`50ACD0` 在当前效果容器内汇总状态 193 行的参数 +310，计算 `1 + Σ(extendLifeRate - 1)`，传给 `511B80`。后者仅对参数 +164 位 0x20（`isExtendSpEffectLife`）打开的效果使用 `dt / 延长倍率` 扣减剩余时间。没有该位的送葬者末段增攻 7036901 作为反例，始终按正常速度倒计时。

持续时间不是在初次施法时一次性乘长。原始寿命仍是原值，后续倒计时变慢。中途加入延长根时，已经存在的效果从该时刻起减慢倒计时；通过实际 `505280` 移除根后恢复正常速度，不把已经消耗的时间倒退。再次施加同一效果仍回到原始寿命，再按当前倍率倒计时。

用于示例的参数来源逐项验证唯一原始行。Magic 行大小 0xAC，首个引用类别位于 +1E、ID 位于 +68；Bullet 行大小 0x15C，`spEffectId0` 位于 +6C。直接引用包括魔力武器、火焰啊赐予我力量、火防护、龙雷庇佑和野兽活力；恩惠赐福、黄金树恩惠与黄金树立誓使用对应 Magic → Bullet → SpEffect 链。这里验证效果来源，不把静态引用当作完整施法与碰撞已经模拟。

普通 +50% 下，“火焰啊，赐予我力量！”的 30 秒变为 45 秒。完整到期时间线覆盖 30／60／120 Hz、普通重复、目录版本重复和不同版本混用；允许单精度累计与清理步骤带来的小幅帧差，不向玩家显示额外固定帧数。

## 持续恢复

原生周期调度和 `506EC0` 恢复包消费者一起执行。恩惠赐福 1643000 的每次 8 点、野兽活力 1685000 的每次 5 点保持不变，约一秒一次的间隔也不变。延长的是总时长，因此可以发生更多次恢复。普通词条装备一份或三份的时间线相同。

测试保留每次恢复的帧号和累计恢复包，不把这些累计值直接视为人物最终实得血量；满血截断、其他治疗倍率与最终资源写入未纳入这一探针。

## 接受者和施法者

构造具有独立效果容器的两个角色，以显式阵营代码 1／2 表示本组友方关系；游戏原生关系表、效果目标判定和接受流程仍执行。`3C7FD0` 先构造标准上下文，在 `3C80A0` 入口只将来源参数 R8 换成另一角色，随后执行 `3DB410 → 50A4C0 → 50C6C0 → 52CC60 → 50D060`，没有用返回成功的桩函数跳过目标判定。

黄金树立誓 1660000 和友方恩惠赐福 1643001 均进入接受者容器。只给来源装备延长词条时，接受者倒计时不变；只给接受者装备时，其倒计时减慢；双方均装备时分别生效，双方比例不相乘。来源容器另有自己的立誓效果，并实际运行其倒计时作为对照，确认来源词条本身确实有效。

初期夹具使用了两个未初始化的阵营代码 0，所有外部来源发放都被原生目标判定拒绝；该结果属于夹具缺失，不能据此声称队友效果不适用。最终证据使用显式友方代码并验证实际发放。
