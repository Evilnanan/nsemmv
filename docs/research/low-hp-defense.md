# 低血量减伤：阈值、叠加与状态切换

适用 Daybreak 2.1.9 Beta2-Hotfix1。探针见 [probe_low_hp_defense.py](../../tools/probe_low_hp_defense.py)，固定输入哈希及全部检查见 [证据](../../data/effect-low-hp-defense-evidence.json)。原生代码隔离执行，`gameplayVerified` 为 false。

## 结论

普通／＋１／＋２在血量低于 40% 时分别将承伤乘以 0.84／0.80／0.76。同等级重复与不同等级组合均按倍率相乘。两份普通版为 ×0.7056，三档各一份为 ×0.51072。不能将减免百分比直接相加。

恰好 40% 血量不生效。每次血量资格更新都会重新读取当前血量与最大血量：回血达到阈值后失效，重新低于阈值后恢复；最大血量改变也会改变资格。没有脱离低血量后继续维持的独立时长。

七个目录词条都只有同 ID 的一个被动根，状态 49，永久节点。完整参数行除八种承伤倍率、叠加类别和显示字段外一致，不能按相同名称合并版本。

| 词条／根 ID | 承伤倍率 | 相同词条重复 | 当前可获取集合 |
| --- | --- | --- | --- |
| 7012300 | ×0.84 | 可叠加 | 是 |
| 7012301 | ×0.80 | 可叠加 | 是 |
| 7012302 | ×0.76 | 可叠加 | 是 |
| 340800 | ×0.60 | 不可叠加 | 否 |
| 8660100 | ×0.77 | 可叠加 | 否 |
| 8660101 | ×0.70 | 可叠加 | 否 |
| 8660102 | ×0.63 | 可叠加 | 否 |

340800 的类别为 20，相同根去重；其他六种类别为 10，分别保留独立节点。不同 ID 的倍率仍能相乘。这些研究结果不改变抽取或可获取规则。

## 原生消费路径

- `4FEA30 → E6E150 → E6E3B0`：实际装备选择与 AttachEffect 到 SpEffect 映射；结果接入真实效果插入。
- `50D060`：插入及相同根的类别去重。
- `3E0D94..3E0DB5 → 426DE0 → 5057D0`：实际角色更新调用块，从角色 +1B8 指向的血量资源读取 +140／+144 整数当前／最大血量，算出单精度比例，再给角色 +190 的效果列表更新资格。
- `50ACD0`：有效性与寿命更新，条件开关不产生关联节点。
- `503800 → EA0980`：消费有效节点，普通／斩击／打击／突刺及魔力／火／雷／圣承伤倍率相乘。
- `50F370 → 511350`：读取受击上下文 +264 的接收类别，与参数 +351 的限制比较。这七个根的该限制都是零。

HP 上限字段为 `conditionHp=40`，原生界限是单精度 `40 × float32(0.01)`，约为 0.399999976；实际整数 400／1000 的比例约为 0.400000006，因此不会通过。七组最大血量及其阈值邻近整数均核对这一浮点运算，而不是将显示名称视为条件证据。极端整数的浮点精度边界不等同于任意精度有理数比较。

受击上下文为独立的 0x300 夹具，显式提供 +25 物理子类型、+264 接收类别及 +2B4 标志。五种倍率输出逐项检查，两组其他状态专用输出保持 ×1。物理子类型 0–3 使用对应减伤字段；无定义的 4／255 在原生 getter 中回退至物理 ×1，其余四种倍率照常。这是无定义输入对照，不作为真实攻击例外展示。
