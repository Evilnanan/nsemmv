# 濒死起身后的血量上限／攻击负面

Daybreak 2.1.9 Beta2-Hotfix1。复现见 [探针](../../tools/probe_dying_curses.py)，原始输入哈希和检查结果见 [证据](../../data/effect-dying-curses-evidence.json)。未进行实机验证。

6851700 在从濒死中起身时降低血量上限 25%，6851701 降低攻击倍率 30%，均持续 60 秒。8831200 则降低血量上限 15%，持续 30 秒。同类重复装备、有效期内再次起身都会增加独立层数，倍率相乘，各层独立到期。例如两层血量上限倍率为 0.5625，两层攻击倍率为 0.49。两份 8831200 的血量上限倍率为 0.7225；它与 6851700 同时生效时为 ×0.6375，两种时长各自保留。

## 起效入口

原始 TAE 2000 中，Type 67 发放标记 6851701 与 8831201 的事件分别出现在 17650／17651，共四个事件，窗口为 0～约 1/30 秒。行为图经 PTCH 指针验证：NearDeathRevival → IsAutoRevival 手动选择器 → 普通／自动起身两个子节点 → 对应动画。实际 `27D0F10 → 27D0400 → 410CA0` 执行原始文件的重定位、事件选择和分派；动画活动时段由调用夹具提供，不把 Type 67 的活动字节当作发放开关。

固定版本 HKS 的 NearDeathCommonFunction 在 Lua 中执行 240 种显式输入组合，覆盖濒死时间／量表、落下、特殊效果、移动以及多个效果并存的分支顺序。进入普通和自动起身的分支均接到这两个动画；落下等进入 NearDeathEnd 的对照分支未误当成起身。完整濒死资源变化与动画调度未模拟。

因此详情明确写“从濒死中起身时”，而非笼统的“濒死时”。事件的短窗口和桥接节点的 0.1 秒寿命均不显示为减益时长。

## 参数与运行链

注意 ID 属于不同表：AttachEffect 6851701 是减攻击词条，根为 SpEffect 6851710；SpEffect 6851701 则是状态 2219 的零寿命标记。8831200 使用另一标记 SpEffect 8831201，状态为 2356；不能按显示名称将它们视为相同触发标记。

| 词条 | 根 | 过渡节点 | 减益节点 | 效果 | 时长 |
| --- | --- | --- | --- | --- | --- |
| 6851700 | 6851700 | 6851702 | 6851703 | maxHpRate ×0.75 | 60 秒 |
| 6851701 | 6851710 | 6851712 | 6851713 | 五类攻击倍率 ×0.7 | 60 秒 |
| 8831200 | 8831200 | 8831202 | 8831203 | maxHpRate ×0.85 | 30 秒 |

前两条根以状态 2219 为条件，8831200 以状态 2356 为条件；满足后发放减益，并经过短过渡节点重新等待下一次触发。减益类别均为 10，寿命分别为 60／60／30 秒，无该状态条件，因此起身标记消失不会提前解除。30／60／120 Hz 的同一短事件窗口虽然会多次调用分派，但每份根在该窗口只新增一份减益。

实际 Curse 槽 3 搭配正面 7000000，经 `4FEA30 → E6E150 → E6E3B0` 选择一／二／三／六份词条，覆盖十名角色和中性身份。库存夹具不证明抽取合法性。

`3C7FD0 → 50D060 → 5057D0 → 50ACD0` 处理自身发放、节点资格和寿命；`6C9150` 以基础上限 1000 验证最大 HP 计算，`502830` 验证五类攻击倍率。失效根不发放减益，失效减益不参与计算。没有将计算所得浮点上限当作已完成的当前 HP 扣除或取整。

## 独立到期与检查范围

时序检查在第 0 秒和第 5 秒分别发放同一已验证的标记，三种词条同时装备一／三份，在 30／60／120 Hz 下执行到第 67 秒。每种词条的层数均经历 0 → n → 2n → n → 0；30 秒版本的两批分别约在第 30／35 秒结束，60 秒版本则在第 60／65 秒结束。后一次触发没有重置前一次的计时，短版本结束也不会移除长版本的层数。每次层数改变时均核对实际血量上限和攻击倍率。

共 426 项检查：装备选择 132、两种实际起身动画／帧率／份数组合 18、完整混合独立到期 6、单独装备对照 12、失效节点 2、HKS 分支 240、标记分离对照 16。标记分离直接从两种 TAE 动画中只选择一个标记、两个标记或均不选择，核对两组词条不会被彼此的状态误触发。独立到期使用已验证的同一标记走原生自身发放，避免在每条时间线上重复解析相同 TAE。
