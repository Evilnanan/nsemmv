# 送葬者：连击末段命中提升攻击力

适用 Daybreak 2.1.9 Beta2-Hotfix1，词条 7036900。固定游戏 EXE、regulation、AttachEffect、SpEffect 和 AtkParam_Pc 哈希的[原生探针](../../tools/probe_undertaker_combo.py)生成[证据](../../data/effect-undertaker-combo-evidence.json)。`gameplayVerified` 为 false。

末段命中后，攻击倍率提高 16%，持续 20 秒。相同词条重复装备不提高倍率；再次触发将现有实例刷新到 20 秒。不受“延长魔法、祷告的有效时间”7006400 影响。

## 装备、命中与倍率

实际执行 `4FEA30 → E6E150 → E6E3B0`：角色 1–9 不选中，送葬者 10 选中；无角色输入 0 也选中，这是选择器的对照输入，不是其他可玩角色。装备排斥 ID 为 -1，重复词条均可被选中，但类别 20 的根 7036900 经 `50D060` 插入后只保留一份。不能把装备阶段未排斥直接解释为可叠加。

根状态 2103，`magicSubCategoryChange1=104`，命中叶为 7036901。`E6D530` 将真实原始攻击行转换为运行时上下文 +124 的标签；`505E90 → 50F230 → 511010 / EA0790` 执行实际匹配，`E6D630` 提供对应攻击 ID 的真实行。原始 AtkParam 行和 0x300 字节运行时攻击包分别存放，未把两者混用，也没有替换判定函数。

当前 11,933 个原始攻击 ID 均唯一。其中 493 行包含标签 104，全部经过实际命中函数检查；另覆盖全部 216 种去重标签组合的代表。具有标记的输入发出一个叶，没有标记不发出。来源枚举 0–12 中的 3／4／10 不发出；上下文标志 32、类别 6 不额外排除此词条。这里不把未追踪来源的枚举命名为某个动作类型，也不把所有带标记的数据行都当作当前游戏中可达的动作。

叶属于类别 20、状态 0、目标为攻击者。五个攻击倍率均为单精度的约 1.16。`502830` 实际执行得到五个通道均为该倍率，重复根和重复叶都不提高结果。禁用节点后得到五个 1。没有新增周期发放或替换链。

## 时长、刷新与延长效果

`50D060 → 5057D0 → 50ACD0 → 511B80` 运行实际插入、资格、更新和倒计时。30／60／120 Hz 的时间线都在约 20 秒清理叶，单精度累计与清理调度允许最多三帧偏差，不把清理帧写成玩家需要遵守的额外时长。

在第 5、10 秒再次触发时，现有叶各刷新至 20 秒；倍率保持 1.16，并且始终只有一份叶。最后一次触发结束后自然到期。

7006400 的状态 193、`extendLifeRate=1.5` 由 `50ACD0` 读取，传入 `511B80`。倒计时是否使用它取决于叶参数 +164 的位 0x20（`isExtendSpEffectLife`），7036901 此位为 0。另一字段 `isContractSpEffectLife=1` 对应独立的缩短路径，不能据此推断它会被延长。探针验证 0／1／3 份延长词条的完整到期时间，另验证 0／1／2／3／6 份下的一秒倒计时，均保持相同结果。
