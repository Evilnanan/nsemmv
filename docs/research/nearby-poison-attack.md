# 周围中毒／腐败时提升攻击力

7260800 在自身或附近敌人陷入中毒、腐败后，获得 **20 秒、攻击倍率 +12%**。重复装备不可叠加；中毒与腐败触发的是同一份增益，同时触发不会变成两层。再次触发刷新持续时间。队友中毒、腐败不触发。

[原生探针](../../tools/probe_nearby_poison_attack.py)与[证据](../../data/effect-nearby-poison-attack-evidence.json)固定 PC EXE、MMV regulation 和原始 PARAM。角色、命中到达及 PARAM 管理器上下文为显式输入，`gameplayVerified=false`。

## 两种通知均可触发

装备词条 7260800 的实际被动根为 **7260802**，并非同 ID 的 SpEffect。根的条件槽 1 为状态 380，槽 2 为状态 2064；两种标记分别命中都能发放 7260803。只检查第一个条件会误判腐败无效。

- 中毒 20005 → 状态 275 的 505 → Behavior2105 → Bullet1005 → 标记 506／状态 380。
- 腐败 21005 → 状态 275 的 1120 → Behavior2108 → Bullet1025 → 标记 1121／状态 2064。

505 与 7260800、506 与 7260801 分别是整行原始字节及解码字段相同的别名。不能因为没有直接引用别名的路径，就认为没有触发来源。不同通知路径也不表示接收端只接受其中一种。

原生 `43BE60 → 3C80A0 → 3DB410 → 42D110` 处理异常命中和发作。受测中毒／腐败均累积 60，抗性 1、59、60 可发作，61 不发作；免疫效果 9642 阻止发作。状态 275 经 `50AA20 → 397570 → 3975D0` 发出通知。

两种弹体都引用 AtkParam_PC 2，寿命 0.5 秒、半径参数 7、单发且无无限命中。`343280 → 347700` 记录实际创建请求，但不模拟场景碰撞。原生关系检查允许自身及受测敌方类型，拒绝不同角色的友方类型。

受损中毒／腐败、低血量中毒／腐败的自身发放，以及 7170103 武器腐败的命中路径均验证。另以旧高等级腐败行 107004 验证它发出中毒通知也可被接收；这不是该行可由当前装备取得的证明。

## 武器强化后的腐败效果

原生 `EA7FC0 → EA9A60` 从实际武器 ID 查基础武器行，将强化类型加上 ID 的等级余数，再查 ReinforceParamWeapon。数据行保持原样；PARAM 管理器与行索引为测试上下文。

随后执行 `6A2FE0..6A307E` 及其跳转分支，将武器三个命中特效字段与强化行的三个偏移相加，收集到武器效果数组。覆盖 34 个带腐败效果的武器条目，各取等级 0～5，共 204 项；不存在强化行的输入也作为对照保留，不视为正常可取得的装备等级。

这些输入收集出的腐败效果均走 1120／1121，仍满足增攻根的第二个条件。不能把参数表中较高等级的旧腐败行直接套到当前武器，也不能把通知 1121 误当成回血词条专用。

## 持续、叠加与刷新

7260803 为类别 20、20 秒、五项攻击倍率 1.12。实际装备选择、根插入及增益插入均验证同 ID 去重。中毒、腐败、别名通知的不同顺序只保留同一个增益；新通知更新寿命，不另开一层。

30／60／120 Hz 的完整时间线均从未生效转为生效，再于约 20 秒后结束。相隔 1 帧、0.1 秒、1 秒、5 秒再次触发，持续时间从新通知重新计算。同类效果重复装备不提高倍率。与催眠增攻的普通版、＋１版组合时，各自倍率相乘。

两个通知发放器的 900 秒寿命、999 秒周期都不是玩家需要等待的触发冷却。受测异常约 40 秒后结束，实际条件清理移除发放器；45 秒时重新造成异常，两种来源均再次发出通知。

攻击消费者 `E6D530 → 502830` 覆盖当前 216 组攻击标签及 13 个输入种类。内部种类 5 不采用该倍率；未确认其完整构造路径，不给它强加玩家可见的招式分类。停用位对照及魔法时长延长对照也执行原生消费者；两种受测魔法延长效果不会延长此增益。
