# 卢恩倍率与固定奖励

Daybreak 2.1.9 Beta2-Hotfix1；输入版本和哈希见 `data/effect-rune-rate-evidence.json`，复现脚本为 `tools/probe_rune_rate.py`。这批执行原生代码的隔离夹具，没有运行游戏。

## 结论

- 6840000：每条获得卢恩倍率 ×0.9，重复装备时相乘。
- 8500000、8852000、8852050：分别 ×1.10／×1.06／×1.09，同类及不同版本倍率相乘。
- 311100：×1.15，同一效果不重复；可与其他倍率相乘。这是不同参数类别的目录版本，不能仅凭同名合并。
- 与塔／神殿的十档卢恩增益相乘，不以“增益减负面百分比”相加计算。
- 致命一击的 600 卢恩和取得样本的 1300 卢恩走固定奖励分支，不受上述倍率影响。

## 原生证据

`4FEA30 → E6E150 → E6E3B0` 读取实际 Attach 行。负面词条放在遗物的 Curse 槽（索引 3），与正面槽的 7000000 配对，核对原生选择位及该槽实际被读取的根；此库存夹具不代表抽取合法性验证。`50D060 → 5057D0 → 50ACD0` 决定有效实例：类别 0 的 311100 保留一份，其余类别 10 的行保留重复实例。`508510` 跳过失效节点，依次相乘原始行 +0xE0 的 soulRate。

`PlayerIns` 虚表由 RTTI 定位为 RVA 2C307F8；槽 +5D0 指向 668300。该方法仅在倍率开关非零时调用 508510，将输入整数转换为单精度、乘倍率，再截断为整数，最后交给 2098C0。因单精度逐次乘算，边界结果不应以理想十进制算式替代原指令结果。

固定奖励调用块 `6713D6..6713F8` 使用 `505AF0` 取得当次 soul 点数，以 `r8d=0` 调用上述真实虚表槽。夹具先激活致命根状态 2039，再加入奖励节点；未伪造有效标志。600／1300 及同时 1900 的结果在 0～6 条减少卢恩词条下均不改变。

共 5579 项检查：装备选择 220、倍率／组合 474、发放开关／数值转换 4848、失效节点 5、固定奖励 28、玩家身份／资源对象 4。原始效果行、资格及计算均使用游戏指令；库存、玩家身份、资源对象和最终写入记录为显式夹具。固定奖励使用原调用块的边界停止，未模拟完整角色更新函数。
