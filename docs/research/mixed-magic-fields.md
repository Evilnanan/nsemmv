# 混合魔法强化的三种场地效果

混合魔法强化的两个同名版本通过同一状态开启火圣、魔圣和魔雷圣寒风的附加场地。三种附加效果各自只保留一份。重新命中会刷新持续时间，火圣保留原有的回血节奏。

| 分支 | 目标 | 附加效果 |
| --- | --- | --- |
| 火圣 | 自身和队友 | 每跳回复 10 点加最大 HP 的 1%，百分比部分向下取整。首次命中立即结算，之后每 0.5 秒一次，最后一次命中后持续约 3 秒。 |
| 魔圣 | 自身和队友 | 攻击精力消耗降低 35%，持续 8 秒。与其他攻击精力消耗倍率相乘，可延长法术效果时间。 |
| 魔雷圣寒风 | 命中的敌人 | 魔力、火、雷、圣承伤倍率提高 20%，持续 20 秒。物理承伤倍率保持原值。 |

## 施法和命中

| 魔法与动画 | 请求及命中链 |
| --- | --- |
| 8012、TAE 2531 的 45010 | Behavior 700000303 → Bullet 10801203 → AtkParam 81201 → SpEffect 7034205 |
| 8014、TAE 2533 的 45010 | Behavior 700000304 → Bullet 10801401 → AtkParam 81400 → SpEffect 7034206 |
| 8023、TAE 2538 的 45010 | Behavior 700000305 → Bullet 10802302 → AtkParam 82310 → SpEffect 7034208 |

从原始 TAE 读取 Type 2 负载，用 `40CD80` 和 `668B30` 核对状态 2047 及行为分派。携带一份或三份状态叶时，每个活动事件都会产生一个请求。寒风的非活动事件也经过 `3975D0`，用于停止发射流程，此时不产生新的生成请求。原生 `3975D0 → 384340 → 383ED0 → 384BC0` 将真实行为行转为生成数据，测试记录 `4B77C0` 的输入并核对真实 Bullet 查询。

对照攻击行和 `535A60` 的自身过滤检查，火圣和魔圣允许命中释放者，寒风排除释放者。分开执行 `43BE60 → 3C80A0` 的命中后流程，比较不同关系类别及自身命中的效果接受结果。寒风的效果行自身允许标志不能单独用来判断法术会命中自己，实际攻击行的自身过滤先将它排除。

## 计时与数值

30、60、120 Hz 的模拟分别使用单次命中、同帧三次命中、0.2 秒重叠及多次刷新。各效果仅保留一个节点，时长从最后一次命中续计。火圣的首次脉冲与后续每 0.5 秒脉冲使用 `506EC0` 读取。3 秒尾端附近的最后一跳随帧步进变化。状态刷新延长剩余时间，保留脉冲节奏。同帧重复命中未增加回血量。

魔圣减耗经 `668730 → 5066A0` 验证，在实际攻击精力消耗计算中乘 ×0.65，再按原有消耗流程处理武器和状态修正并取整。魔圣的 8 秒状态支持法术时长延长。火圣的回血和寒风的承伤增加不受该类延长影响。寒风经 `503800` 读出的五组承伤倍率为 `[1, 1.2, 1.2, 1.2, 1.2]`。
