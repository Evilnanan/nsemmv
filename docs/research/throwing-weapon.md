# 提升投掷武器的攻击力

320906 对适用的投掷武器攻击提供 **+10% 攻击倍率**，重复装备不可叠加。飞刀、火焰壶等投掷道具不受此词条强化。

[探针](../../tools/probe_throwing_weapon.py)与[证据](../../data/effect-throwing-weapon-evidence.json)固定 EXE、regulation、SpEffect、AttachEffect、AtkParam_Pc、BehaviorParam_PC、Bullet、EquipParamWeapon、EquipParamGoods 以及实际读取的七份 TAE。`gameplayVerified=false`，原生代码在隔离对象中执行，未进行完整游戏实测。

## 倍率与叠加

`4FEA30 → E6E150 → E6E3B0` 对所有职业输入选择根 20381100。根为类别 0、状态 0、永久有效，五种攻击倍率均为 1.1，适用标签 250。`50D060 → 5057D0 → 50ACD0` 实际插入、去重和更新；一／二／三／六份重复根均只留下一个节点，倍率不再增加。停用或移除唯一节点后恢复为 1。

`E6D530 → 502830` 使用原始攻击行转换标签并计算倍率。当前 196 条攻击行包含 250，另覆盖全部 216 种标签组合的代表。零／一／二／三／六份装备均有对照；显式来源类型 3、4、5、10 被排除，不猜测这些内部类型对应哪些玩家动作。

综合投掷道具强化 7006504 使用 108／120／121，与当前包含 250 的攻击行没有交集。零至三份两种词条混用时，各自只影响适用攻击，没有串用倍率。火焰壶 300 和投掷匕首 1700 的三个等级引用均从实际 Goods／Bullet 行读取，并通过原生攻击消费者验证倍率保持为 1。

## 动画与职业专用分支

候选武器从实际 Behavior `variationId` 与武器 `behaviorVariationId`／`heroBehaviorVariationID` 匹配；候选动作文件取普通、特殊及职业专用动作引用。该匹配仅用于寻找证据，不能将文件中的全部动作视为游戏内一定可达。

`27D0F10 → 27D0400` 对原始 TAE 执行重定位和事件遍历，`40CD80 → 668B30` 使用实际事件解析 Behavior 请求。武器 +292 的职业 ID 通过原生 `EA76F0` 读取，+294 的专用 variation 也由原生解析器选择，不能统一替换为零。输入角色为 1 和 5，实际装备 ID 为对应候选武器。

已执行 204 个 Type 2 事件，分别覆盖两种角色和活动／非活动状态，共 816 项。活动请求来自流纹圆刃刀、流纹大槌、流纹斧、流纹枪、穿刺者矛、魔像拳头、流纹短剑的对应文件；非活动状态没有请求。七份 TAE 分别为 2251、2250、2248、2247、2266、2259、2053。

普通角色使用流纹大槌时，例举事件选择 101210xxx；角色 5 则读取职业专用 102351xxx。其 30210／32210 动画事件在专用分支引用直接攻击 2350125／2350325，倍率为 1，其他四个对应投掷事件仍为 1.1。这里尚未将两项动画编号命名为具体操作，也未确认它们在完整动作图中的选择条件。

`3975D0` 请求末端是记录器，不实际创建攻击或投射物。选出的 Behavior 为类型 0 时使用直接攻击行，类型 1 时读取 Bullet 的攻击引用，再交给独立对象中的原生倍率消费者。该组合验证没有模拟投射物生成、碰撞或最终伤害。
