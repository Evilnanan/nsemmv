# 铁之眼击杀观察力成长（部分解明）

`7280100` 与 `7280101` 是同一个实际效果的两个目录入口。已确认自身观察力每次击杀增加 **1 点**，最多 **99 档／+99 点**；重复装备及两入口混用不会加快自身成长。同一帧收到多个击杀奖励通知会分别累计。

**队友成长的实际投递与合并尚未确认。** 本批只补充自身成长详情，整体叠加分类继续为「待确认」，不增加已完成叠加条数。固定 EXE 与 MMV 参数的隔离原生执行不等同于实机或联机验证。

## 原生触发、成长和消费

`4FEA30 → E6E150 → E6E3B0` 检查两个目录入口在 0～10 角色标识、1／2／3 份装备下的选择。铁之眼 3 和通用标识 0 可通过，其他标识不通过；两入口都只指向根 `7280100`。根的容器类别 20 使重复装备仅留一份。

`668380 → 50A150 → 3C7FD0 → 3C80A0 → 3DB410` 执行奖励通知、实际授予及成长处理。普通与特殊分支都能产生 `7280101`，后者在没有独立特殊奖励效果时回落到普通分支。该桥接效果约 0.1 秒后替换为成长种子 `7280201`；这不是 0.1 秒的增益寿命或击杀冷却。同帧 1／2／5／10 次通知在 30／60／120 Hz 下均逐次计数。

种子通过容器类别 204、优先级 6 的原生成长处理推进至 `7280299`，到 99 档后不再增长。每档 `itemDropRate` 增加 0.01，状态 66，寿命 -1；`5071B0` 对该字段相加，`6C7F30` 加入感应曲线的观察力系数，`6C7E40` 转换为显示点数。它增加的是观察力点数，不能解释为每次将既有观察力乘以 1.01。

进一步执行 `2099C0 → 584220 → 501840`，将真实成长后的效果列表复制到玩家资料的效果容器，再经掉落入口 `56AD70 → 20CE40 → 584480 → 6C7F30` 读取。使用当前参数的 `CalcCorrectGraph 140`，感应 0／10／30／40／60／99 以及成长 0／1／2／10／99 档的 30 组结果均为基础系数加上 0.01×档位。资料容器初始状态为显式夹具，未声称运行了整个资料构造器。

直接移除根效果后，已有成长叶节点保留；再次收到击杀通知不再成长。此项验证的是 `504E80` 移除和后续通知，不将其泛化为所有装备切换、死亡、出征或重载规则。`saveCategory=9` 和遗物的 `permanentSpEffectId` 单独不能证明跨局保留或初始自动赠送一档。

## 未解决的共享路径

静态读取表明队友共享标志位在成长叶节点上，而遗物的永久根没有该标志。此前团队遗物管理器路径只导出遗物的被动根；本批未把这一观察当成「队友无效」的证明。可能涉及的动态效果合并、共享掉落归属、队伍生命周期与 DLL 改写仍须继续追踪。

也不将接收一个外部成长种子的容器结果，当成实际网络会发放该种子的证据。相关边界保存在研究账本和机器证据的 `openQuestions`。
