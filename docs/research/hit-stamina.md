# 命中恢复精力：选择、叠加与短暂恢复窗口

适用 Daybreak 2.1.9 Beta2-Hotfix1。[原生探针](../../tools/probe_hit_stamina.py) 与 [证据](../../data/effect-hit-stamina-evidence.json) 固定 EXE、regulation、AttachEffect、SpEffect 和 AtkParam_Pc 哈希。`gameplayVerified` 为 false。

普通版 7100100 在一次恢复触发中恢复 2 点精力，＋１版 7100110 恢复 3 点。同等级重复不增加恢复量，两版同时装备合计 5 点。精力写入使用实际角色更新调用块与原生 setter，结果截断到当前最大精力，不会超出上限。

## 装备与生效链

`4FEA30 → E6E150 → E6E3B0` 的装备选择不能省略：普通版的装备排斥 ID 为 -1，重复词条均被选中，但其类别 20 根在插入时去重；＋１版的根虽然属于类别 10，装备排斥 ID 300 已使重复词条只选中一份。因此不能只看 SpEffect 类别就把＋１版写成可重复叠加。

两种根的状态都是 2103，实际 `505E90` 调用 `50F230 → 511010` 和 `EA0790` 后返回对应的 `atkOccurrenceSpEffectId`。普通版返回 7100101，＋１版返回 7100111。叶节点都以攻击者为目标、类别 20，分别包含精力定值 -2／-3，且没有百分比精力恢复。

探针还直接插入三份＋１根作绕过装备选择的对照：此时确实发出三个相同叶 ID，但重复叶在实际插入时仍去重，不会恢复 9 点。这个夹具不代表合法装备选择能产生三份根。

命中类型输入 0–12 中，3／4／10 不发放本组叶。测试中的额外标志 32、攻击类别 6 不排除此组；它们会影响部分武器限定回 HP／FP 词条，不能套用到这里。这里只记录显式运行时输入，不给未追踪来源的枚举强加武器或法术名称。

## 恢复时序

叶的寿命为 0.3 秒，周期为 0.4 秒。首次命中后的首次有效更新恢复一次。若持续命中，重新施加会延长短暂窗口，但不会让每次命中都立即恢复；保留的周期约每 0.4 秒恢复一次。停止命中后，在末次命中维持的窗口结束前仍可能追加一次恢复。

这不是“恢复持续 0.3 秒”，也不是简单的全局 0.4 秒冷却。窗口清理后再命中可以创建新实例并立即恢复；窗口内再次命中保留已有周期。以隔离夹具 60 Hz 为例：

- 第 0 帧单次命中，第 1 帧恢复一次。
- 第 0／1 帧命中，仍仅第 1 帧恢复一次。
- 第 0／12 帧命中，在第 1／25 帧恢复，第二次恢复出现在停止命中之后。
- 第 0／30 帧命中，在第 1／31 帧各恢复一次。

0.3 秒寿命、0.4 秒周期相遇的边界受单精度运算与更新／清理步影响。特别是两次命中相隔 0.1 秒时，30／60 Hz 夹具可在周期末尾追加恢复，120 Hz 夹具可能已清理节点；证据保留逐次施加前的节点状态和原生插入返回值。网页使用“约”和“可能”，不把边界结果写成固定帧数承诺。

## 实际精力写入

角色更新块 `3DAEB4..3DAF00` 调用 `5085A0`，后者只累计有效且本更新步恢复标记打开的节点，从参数 +B0／+B4 取百分比与定值。调用块读取资源对象 +160 最大精力，完成百分比计算、截断取整与符号转换，再调用 `4261D0 → 427F00`，更新 +15C 当前精力并限制不超过最大值。探针原样执行这条路径，没有用 Python 加法代替实际写入。

资源当前值包括负值、零、接近上限和满值；负值输入仅验证原生恢复加法，不声称已模拟造成负精力的动作。自然回精、攻击耗精和其他资源修改未混入隔离测试。
