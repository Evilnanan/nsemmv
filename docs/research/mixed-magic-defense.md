# 混合魔法强化：纯圣防护

隐士词条 `7034200`／`7034201` 对纯圣混合魔法增加一层自身防护：额外承伤倍率 ×0.8，默认持续 30 秒。纯圣原有防护为 ×0.9，两层同时存在时为 ×0.72，即承伤降低 28%。重复装备不叠加。

**两层的重施行为不同。** 重新施放会刷新原有防护；额外防护尚未结束时重新施放，不刷新其时长。额外防护结束后再次施放，可以重新获得。

原有防护与「黄金树立誓」等同类别增益互相覆盖，后施加的替换先施加的；额外的 ×0.8 防护独立保留，可以与这些增益相乘。两层防护均受法术有效时间延长影响。

## 实际施法与动画入口

当前 `Magic 8003` 的原始行名为纯圣防护，动作类型 128、第二引用槽为 `SpEffect 1800300`。当前行为图的 `MagicFireRight_CMSG` 及其上半身版本均含 `a528_045010`。使用固定 TAE 2528 的原始字节执行原生重定位 `27D0F10` 和事件迭代 `27D0400`，得到施法动画 45010 中两个入口：

| 事件 | 起止时间 | 实际作用 |
| --- | --- | --- |
| Type 64、槽 1（从零计数） | 约 0.5667～0.6000 秒 | 原生 `40EB30 → E91FD0 → 3C7F40` 请求向自身施加 1800300 |
| Type 67、7034204 | 约 0.5667～0.6333 秒 | 原生 `410CA0 → 40FF20` 发放额外防护，受状态 2047 控制 |

基准防护类别 160、额外防护类别 20，均为 30 秒。额外防护的资格要求来自词条维护链的 2047 状态。0／1／3 份词条、30／60／120 Hz 的九条完整时间线验证：没有词条时只有 ×0.9；装备词条时 ×0.9 ×0.8 = ×0.72。五个承伤通道均由原生 `503800` 读取；到期均恢复为 1。到期后重新发放，两层寿命恢复到 30 秒。

施法运行时生成的自身发放请求被显式交给独立原生接受者执行。本探针没有将两个隔离对象伪装为完整游戏场景；身份、选中动画窗口与请求投递均列入夹具边界。

## 为什么额外防护不刷新

Type 67 并不直接无条件重新授予效果。`40FF20` 先调用 `509150` 查询该效果是否已经存在：

- 不存在时，经 `3C8BE0` 授予新节点。
- 已存在时，只调用 `50A630` 给节点 +0x7C 设置活动标记，不重置寿命。

六条重施时间线分别使用 1／3 份词条和 30／60／120 Hz。在第一次施放后第 5 秒重施，原有 1800300 刷新到第 35 秒附近；额外 7034204 仍在第 30 秒附近结束。第 32 秒只剩 ×0.9。实际分支记录为一次新授予、一次现存节点标记；不能用直接调用 `grant(7034204)` 的刷新结果代替真实动画入口。

无词条时，7034204 可以作为不满足条件的节点留在容器中，但没有减伤，也不消耗有效计时。移除整个维护链后额外防护失效，恢复 2047 状态后继续生效。这是状态资格测试，不是完整游戏中的卸装、跨出征或保存行为承诺。

## 与其他增益、时长延长的组合

对 1730、1768、1660000、1661000、1662000、99590 六个类别 160 节点，分别测试先施加／后施加及 0／1／3 份词条，共 36 组组合。原有 1800300 与对方只保留后施加者，额外 7034204 独立保留。

「黄金树立誓」的名称与实际行由当前 MagicName 6600、Magic 6600 → Bullet 10660000 → SpEffect 1660000 核对，避免只凭效果 ID 命名。同类覆盖可能同时移除该增益中的攻击加成，不应理解成只覆盖减伤字段。

时长延长测试包含无延长、7006400、8330500、各自三份及两者组合。两层均按原生延长倍率减慢计时；7006400 重复只保留一份，8330500 多份的延长比例相加，减伤倍率不变。四种禁用掩码分别排除一层时，另一层仍独立生效。
