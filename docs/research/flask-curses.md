# 喝瓶时承伤与发狂负面

Daybreak 2.1.9 Beta2-Hotfix1。输入哈希和检查结果见 [证据](../../data/effect-flask-curses-evidence.json)，复现见 [探针](../../tools/probe_flask_curses.py)。本批执行原生隔离检查，未进行实机验证。

6850900 在喝瓶动作期间使承伤倍率增加 45%；目录中的 8801000 和 8801050 分别为 33% 和 46%。同版与不同版本均相乘，两条 +45% 为 ×2.1025。当前可获取的是 6850900。

6851100 每 0.1 秒发放一次 6851101，每次累积 8 点发狂；重复装备累积相加。30／60／120 Hz 下，每条连续两秒均产生 20 次累积，共 160 点；停止动作标记后不再追加，原有累积不会被这个标记的结束清空。自然退条不在这段模拟中。

## 动作与状态链

原始 TAE 2000 中 50110～50117 各有一个 Type 67 事件发放 8801001。原生 `27D0F10 → 27D0400 → 410CA0` 执行实际文件的重定位、事件选择与分派。8801001 是状态 2352 的零寿命标记，四条根效果均以该状态为条件。

经 PTCH 指针检查的行为图对应 ItemDrinkStart、ItemDrinking、ItemDrinkEnd 的普通／IsBaphometBuff 分支，以及 ItemDrinkEmpty、ItemDrinkNothing；全身和上半身共 14 条状态路径，包括共用动画的 MP 起手和饮用。实际 HKS 上半身更新函数在显式输入下执行 224 种组合：正常衔接、空瓶、动画终止、事件标记、特殊增益和公共取消。MP 饮用结束同样转入 ItemDrinkEnd，没有臆造独立的 MP 收尾状态。

事件的 0～100 秒是覆盖当前动画的事件窗口，不是持续百秒的负面效果。事件调用者的活动时间由夹具提供；退出该调用窗口后，状态资格和负面消费者实际停止。完整 Havok 调度及受击／闪避导致状态切换的时机仍待核对。

实际 Curse 槽 3（搭配正面 7000000）经过 `4FEA30 → E6E150 → E6E3B0` 选择根，覆盖四个版本、一／二／三／六份、十名角色与中性身份。库存夹具只验证运行时选择，不证明抽取合法性。承伤使用原生 `503800` 聚合五类倍率；重复实例保留，失效节点被忽略。

## 发狂累积与发作须分开

6851101 的 stateInfo 为 437，带有 1 秒寿命、2 秒周期、cycle 49060、replace 1110 以及 HP／FP 损失字段。它通过实际 `3C7FD0` 自身发放路径处理异常累积。未达到阈值时，该节点立即移除，不执行这些持续／损失分支；因此不能把“一秒持续时间”和 HP／FP 损失放在喝瓶累积块中。

阈值 8／9／16／17、资源最大值 101／1000 的八组检查确认：累积达到阈值才留下发作节点、重置该异常的剩余抗性并产生一次 HP／FP 请求。基础 HP 损失为最大值的 15% + 100，FP 损失为最大值的 10% + 30，原生单精度计算后取整。未发作的各次累积请求均为零损失。发作期间重复发放不会重复造成这次损失；节点结束后发出 1110。49060／1110 的状态通知未被解释为已核实的硬直动作或退条机制，详情不展示一秒硬直。

旧详情还误用了“闪避后的当下……”的说明文本；仅对 6851100 的生成详情改为“使用圣杯瓶时，累积发狂量表”，保留原始提取数据。
