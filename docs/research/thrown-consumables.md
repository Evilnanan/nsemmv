综合词条引用三个单项＋１的原始效果行：7040501、7040301、7040401。相同 ID 并不意味着覆盖：类别 10 效果在原生容器内保留多份，匹配攻击的倍率相乘。普通版、＋１版、综合版之间也相乘。

例如综合版与对应单项＋１合计 ×1.69；再加一份单项普通版是 ×1.9435。三份综合版对只匹配一种分类的攻击为 ×2.197。

## 装备选择与攻击消费者

`4FEA30 → E6E150 → E6E3B0` 执行七种词条的原生装备选择与各被动效果解析，覆盖角色代码 0～10、1／2／3／6 份。十个实际职业均允许使用。选择位图也会标记没有输入效果的其他槽位，探针保留完整位图，只将实际输入槽位对应的被动交给容器；不能把无输入槽位的标记解释为额外效果。

`50D060` 插入、`5057D0 → 50ACD0` 资格与更新、`E6D530 → E6D3E0` 原始攻击行标签转换，以及 `502830` 攻击倍率消费者执行原始指令。检查全部 394 个匹配分类的攻击行和每种标签集合的代表行，合计 595 个唯一输入。三种分类分别覆盖 291／52／53 行，其中两行重复计入。

五种伤害通道得到相同倍率；输入来源类别 3／4／5／10 被消费者排除。只含投掷武器分类 250 的对照攻击与普通无匹配标签攻击不获得加成。这里保留来源类别数字，不根据未验证的名称映射扩大游戏内说明范围。禁用节点后加成消失。

原生 `505280` 的参数是当前列表序号，不是稳定句柄。最初依次使用插入时返回的序号，会在删除后错移其他节点；最终探针改为从尾到头删除，并在每一步检查实际剩余 ID 和倍率。移除一份不会抹掉剩余的同 ID 实例；这是容器移除验证，没有模拟完整装备重建。

## 蜷曲火焰与道具等级

EquipParamGoods 当前行长 0xE0，默认／二级／三级引用位于 +04／+B8／+C0。Bullet 当前行长 **0x15C**，首个 s32 为攻击 ID。探针校验所有收录道具引用的原始字节和所有相关表 ID 唯一性。

蜷曲火焰 Goods 2003180：默认 Bullet 210318000 → Atk 210318000；二级／三级 Bullet 210318020／210318040 → Atk 210318001。两种攻击均有分类 121，因此适用辉石／重力石强化和综合投掷强化。

`3844C0` 实际执行道具引用选择，以火焰壶、投掷匕首、杜鹃辉石、蜷曲火焰为代表，覆盖全部角色代码及三级输入。学者代码 9 会选择二／三级引用，其他角色仍选择默认引用。每个选中的攻击行随后进入原生标签和倍率消费者。角色身份、熟练度及可使用状态是显式输入，未模拟熟练度获取。

## 双分类行与边界

Atk 321330、321340 同时有 120 和 121，一份综合强化在消费者内产生 ×1.69。它们的实际武器／动作可达性尚未证实，因此不把它们称为可使用的投掷道具，也不向玩家列出未经确认的特例。
