# 全词条机制研究目标

验收目标：尽可能解明当前 Daybreak 2.1.9 Beta2-Release 词条的实际数值、触发条件、叠加、有效时间和副作用，并将有依据的结论写入网页版详情。页面保持简洁，不增加研究过程、抽取合法性或训练场说明。

研究范围包含当前目录的 2241 个条目。优先核对 885 个可获取遗物定义涉及的 637 个词条（包括商店遗物）；其余目录条目继续检查，不将未开放获取的能力混同为可创建遗物。

## 验收依据

- 每条结论绑定当前 regulation、游戏代码及实际加载的 Mod 资产。
- 区分数值已读取、触发已接通、叠加已核对、游戏内已实测，不以有数值字段代替完全解明。
- 叠加只使用“不可叠加”“可叠加”“不同等级可叠加”；缺少依据时保留“待确认”。不使用玩家反馈作为结论依据。
- 一次性效果不展示内部节点寿命；真正影响再次触发的刷新、累计清零等机制需说明。
- 优先用简短的总括规则，仅在必要时列例外；不重复描述玩家已能从名称理解的内容。
- 每批完成后更新证据、运行相关回归、提交并部署；保留明确的剩余问题，不能为了提高覆盖率填入猜测。

## 基线与推进顺序

任务开始时：637 个可获取遗物词条均已登记；447 个有字段或替换法术详情，432 个有已解读数值，231 个有原生叠加结论；原生隔离执行 748 组检查。此基线不代表完全解明数量。

1. 补齐动作脚本、动画事件、Behavior/Bullet 与参数之间的触发引用，处理目前只有触发标记的词条。
2. 核对通用能力值、恢复、增伤、承伤、耗蓝、异常积累与物品发放的共享计算路径及单条差异。
3. 核对角色专属、连续攻击、低血量、临时状态和地点成长的计数、阈值、刷新与上限。
4. 对全部目录逐条复核展示内容，移除错误的时长、重复分支及未证实的叠加解释。
5. 记录仍受资产、原生调用或运行条件限制的未解项，交付可复查的进度和已部署版本。
