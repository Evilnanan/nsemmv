# 针对中毒、腐败、冻伤目标的攻击强化

适用 Daybreak 2.1.9 Beta2-Hotfix1。探针见 [probe_target_ailment_attack.py](../../tools/probe_target_ailment_attack.py)，固定输入哈希及全部检查见 [证据](../../data/effect-target-ailment-attack-evidence.json)。原生代码隔离执行，`gameplayVerified` 为 false。

## 已核对的机制

三个异常系列的普通／＋１／＋２版分别提供攻击倍率 ×1.10／×1.16／×1.20。同一词条重复装备只有一份根节点生效；不同等级倍率相乘，三档同时生效为 ×1.5312。目标同时处于多种对应异常时，各系列也可同时生效。

这不是给攻击者添加定时增攻：受击计算使用当前目标的有效异常状态。改打没有对应异常的目标不享受加成；返回原目标又能生效。攻击者自身中毒、腐败或冻伤不能代替目标状态。目标的异常节点失效或移除后，该项倍率不再参与计算，没有另一个增益持续时间。

| 系列 | 普通词条／根 | ＋１词条 → 根 | ＋２词条 → 根 | 目标状态 |
| --- | --- | --- | --- | --- |
| 中毒 | 7260000 | 6260000 → 7260001 | 6260001 → 7260002 | 2 |
| 猩红腐败 | 7260300 | 6260300 → 7260301 | 6260301 → 7260302 | 5 |
| 冻伤 | 7260400 | 6260400 → 7260401 | 6260401 → 7260402 | 260 |

另外，目录的 6260002 → 7260003、6260402 → 7260403 也是 ×1.20，但属于不同根 ID，不与＋２版去重；各自可和同系列＋２相乘为 ×1.44。不能根据显示名称或数值相同推断它们是别名。这两个目录版本当前不在可获取词条集合中，研究结论不改变获取或抽取规则。

## 实际消费链与数据结构

`4FEA30 → E6E150 → E6E3B0` 核对实际装备选择及根映射。上述 11 个词条的装备排斥 ID 均为 -1，各自只有一个被动根。重复词条进入选择结果，但实际 `50D060` 插入相同类别 0、相同根 ID 时只保留一份；不同根互不覆盖。

根均为状态 2110、永久节点，`enemyStateInfoTrigger` 指定目标的 2／5／260 状态。完整解码行之间只在该目标状态及五种攻击倍率字段上有差异，攻击筛选条件一致。

实际受击调用块为 `43A5E1..43A605`，位于 `439E80..43AE9F`。它从攻击者对象 +190 取得效果列表，由 `42C130` 从接收方上下文取得目标列表，将当前五种攻击分量和运行时攻击数据传入 `5025E0`。探针执行这段原始调用块，也直接调用消费函数作对照；攻击者不存在或目标列表为空时不增加倍率。

消费函数通过 `50F230 → 511010` 检查攻击输入，再读取 SpEffect +266 的目标状态要求，调用 `508E20` 检查目标列表。后者先检查状态缓存，再遍历实际有效节点；失效的目标异常节点不会仅凭缓存继续触发加成。随后五个原生倍率读取器分别乘入对应攻击分量。

运行时攻击数据不是 0x1D0 的 AtkParam_Pc 原始行。前期探索中传入原始行仅用于定位数值消费函数，未作为本批验证。正式探针使用独立的 0x300 运行时包：显式提供来源类型、致命标志、额外标志和来源 ID；实际 `E6D530` 从固定 AtkParam_Pc 行转换的标签位集放入 +124。`50F230` 的输出逐字段核对，覆盖 +122 来源、+124／+134 标签、+121 致命、+161 标志及其他来源字段。原始行大小和运行时结构不混用。

当前参数中 216 种不同攻击标签组合全部经过原生转换和消费；13 种来源枚举及两个上下文标志也逐项核对。枚举和包字段为显式输入，不能据此声称已模拟所有武器、弹体、施法和碰撞路径。

常规攻击聚合 `502830` 对这组根在 13 种来源输入下均保持 ×1，不会先无条件增加攻击再重复叠乘。加成位于上述检查当前目标状态的独立步骤。

## 检查范围

共 2,393 项：

- 装备选择 484：11 个词条、一／二／三／六份，十名角色与中性身份，并连接实际插入去重。
- 重复装备与目标异常组合 440：零／一／二／三／六份、三种异常的全部八种组合。
- 异等级／异版本／不同异常混合 232：包括逆序插入及重复整组。
- 来源与上下文标志 572，原生标签组合 216。
- 攻击者词条／目标异常的失效节点对照 352。
- 更换目标及“只有攻击者患异常”对照 11。
- 目标异常寿命 9：代表性中毒／腐败／冻伤节点在 30／60／120 Hz 下自然移除，倍率随对应有效状态消失。
- 常规攻击聚合对照 13，确认没有无条件增攻。
- 实际受击调用块 64：包含非等值攻击分量、零分量、空攻击者及空目标。

寿命检查使用 8110000、8110400、107504 三个代表性节点（40／40／30 秒）。这些时长属于测试所用的目标异常，不是遗物加成持续时间，也不代表所有来源的异常持续时间。网页仅描述目标状态条件，不显示这些时长。

尚未执行完整运行时攻击数据构造、碰撞、最终减伤和 HP 写入，也未模拟异常累积、免疫、发作、苔药及重新施加的完整入口。装备重建、死亡／重载和多人交互仍保留为待查项。调用块的对象及边界输入是明确夹具，不是实机验证。
